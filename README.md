# Psia Przystań – demonstracyjna podstrona SEO

Projekt statyczny przygotowany jako materiał do zadania z przedmiotu „Analityka internetowa”.

## Pliki
- `index.html` – podstrona z artykułem i elementami SEO.
- `style.css` – responsywne style.
- `sitemap.xml` – mapa witryny.
- `robots.txt` – podstawowe wskazówki dla robotów.
- `images/` – tutaj dodaj dwa własne zdjęcia.

## Przed publikacją na GitHub Pages
1. Wgraj zawartość folderu do repozytorium GitHub.
2. W ustawieniach repozytorium wybierz **Settings → Pages** i opublikuj stronę z gałęzi `main` (folder `/root`).
3. Odczytaj publiczny adres strony, zwykle `https://TWOJ-LOGIN.github.io/TWOJE-REPO/`.
4. W `index.html`, `sitemap.xml` i `robots.txt` zamień `TWOJ-LOGIN` oraz `TWOJE-REPO` na prawdziwe wartości.
5. Dodaj do folderu `images/` pliki o dokładnych nazwach:
   - `pies-w-mieszkaniu.jpg`
   - `pudel-miniaturowy-spacer.jpg`
6. Sprawdź, czy oba zdjęcia wyświetlają się po publikacji.

## Google Search Console
Dodaj usługę typu **Prefiks adresu URL**, podając dokładny adres GitHub Pages. Weryfikacja i indeksowanie nie są natychmiastowe. Po weryfikacji prześlij adres `sitemap.xml`. Samo przesłanie mapy nie gwarantuje indeksacji.

## Ważne uwagi do zadania
- Tagi i kategoria są pokazane jako widoczne elementy redakcyjne w HTML. To nie jest system CMS ani automatycznie generowane archiwum tagów.
- `meta keywords` jest umieszczone jako demonstracja metadanych, ale Google nie używa tego znacznika do ustalania pozycji.
- Przed oddaniem uzupełnij szablon DOCX i dołącz wymagane zrzuty ekranu.
